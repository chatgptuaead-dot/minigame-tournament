# 🎮 Minigame Tournament

A real-time multiplayer party game with 8 minigames and a tournament system for 2–12 players.

## Quick Start

```bash
npm install
npm start
# Open http://localhost:3000 on all devices (same network)
```

For LAN play, use your computer's local IP (e.g. `http://192.168.1.x:3000`).

## Games
- 🏓 Ping Pong — real-time 1v1
- ⚡ Reaction Race — tap as fast as possible
- 🏹 Archery — hold and release to shoot
- ⚽ Penalty Shootout — drag to aim & kick
- ⛳ Mini Golf — 3 holes, lowest strokes wins
- 🚗 Car Racing — 3 laps, arrow keys or tilt
- 🎰 Pinball — Z/X or tap sides for flippers
- 🚀 Space Blast — 60-second asteroid shooter

## Tournament Formats
- **2–8 players:** Single elimination bracket (with byes for non-powers of 2)
- **9–12 players:** Group stage → Semifinals → Final
